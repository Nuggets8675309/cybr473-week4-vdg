# CYBR 473 - Scripting Assignment #4 - Searching for Digital Images with Python

Detailed requirements are stated in the `src/wk4_assignment1.py` script.

## What to submit

1. Your `.py` file
2. A screenshot or video from within your IDE demonstrating script execution
3. Any other documents required in the assignment

## How to submit

1. Create your own repository from this template: **Use this template** then **Create a new repository**.
2. Name it exactly `cybr473-week4-yournetid`, replacing `yournetid` with your UA NetID. Submissions are collected in bulk by repository name, so a repository named anything else may not be picked up for grading.
3. Set the repository visibility to **Private**. Never make graded work public.
4. Invite your instructor as a collaborator, using the GitHub username listed in D2L. A repository the instructor cannot open cannot be graded.
5. Clone the repository in PyCharm with **Get from Version Control**.
6. Commit meaningfully as you work: several small commits with clear messages, not one large commit at the end. Your commit history is part of what is graded.
7. Submit the repository URL in D2L. The D2L submission is what gets graded.

Read [`Guidelines.md`](Guidelines.md) before you submit. It applies to every assignment in this course.

Good luck
